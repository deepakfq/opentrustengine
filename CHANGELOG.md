# Changelog

All notable changes to the OpenTrustEngine SDK family will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] — 2026-04-29

### Added
- First public release.
- `@ote/sdk` — TypeScript client for the OpenTrustEngine and OneTrustEngine REST APIs.
- `@ote/widget` — embeddable trust badge widget (light/dark/glass/compact themes).
- `@ote/connectors` — connector framework with built-in adapters for Razorpay, Cashfree, PayU, Shopify, WooCommerce, and Tally.
- `@ote/shopify` — Shopify app for automatic trust scoring.
- `@ote/tally-agent` — Electron desktop agent for Tally ERP sync.
- WordPress / WooCommerce plugin (`opentrustengine-woocommerce`).
