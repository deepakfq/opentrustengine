# next-app — Next.js demo with widget embed

A minimal Next.js 14 app that embeds the `@ote/widget` trust badge.

## Run

```bash
npm install
npm run dev
# open http://localhost:3000
```

## What it shows

- Server-rendered page with a hero section
- `@ote/widget` mounted client-side via `<script>` tag
- Live trust badge for a sample company UUID
