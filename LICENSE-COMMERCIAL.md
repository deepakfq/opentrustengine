## When you need a commercial license

You **must** obtain a commercial license before using OpenTrustEngine if any of the following apply to your use:

1. **Closed-source distribution.** You ship a product (mobile app, desktop app, on-premise software, embedded firmware) that links against OpenTrustEngine code, and you do not want to release your product's source code under the AGPL.

2. **SaaS / network use without source release.** You operate a network service (web app, API, mobile backend) that uses OpenTrustEngine — including modified versions — and you do not want to make the complete corresponding source code of your service available to your users under the AGPL.

3. **Sublicensing or redistribution under different terms.** You wish to redistribute OpenTrustEngine (or a derivative) to your customers, partners, or end users under terms more permissive than the AGPL.

4. **Removal of attribution or branding requirements** beyond what is required by AGPL §7.

If none of the above apply — for example, you are running OpenTrustEngine for internal use only, or you are operating a public service whose source is published under the AGPL — you do not need a commercial license. The AGPL grant is sufficient.

## Frequently asked questions

**Q. We're a non-profit / academic researcher / individual hobbyist. Do we need to pay?**
No. The AGPL grant is free for everyone. You only need a commercial license if you cannot comply with the AGPL.

**Q. We use the `@ote/sdk` only as an HTTP client to your hosted API. Do we need a commercial license?**
No. Calling a remote service via HTTP does not create an AGPL combined work. Use the SDK freely.

**Q. We embed `@ote/widget` on our public website. Do we need a commercial license?**
No, provided you do not modify the widget. The widget is served as-is; you are not creating a derivative work.

**Q. We have modified `@ote/connectors` to add a new payment gateway, and we run this internally. Do we need a commercial license?**
Not if your service is purely internal. If you offer it as a network service to external users, AGPL §13 requires you to publish the modifications. If you do not want to publish, you need a commercial license.

**Q. We are using OpenTrustEngine in a customer pilot. Can we evaluate before paying?**
Yes. Please write to **deepak@freaquer.com** for a no-cost evaluation license, typically valid for 60 days.
